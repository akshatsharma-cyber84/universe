# NEWSer

**Know what matters. In seconds.**

A fast, trustworthy, personalized information + creator ecosystem.

## Made by AK Industries

## Features

- 📰 30+ demo news stories with full details
- 🎯 Personalized "For You" feed
- 🔍 Source transparency and verification
- ✍️ 15+ creator profiles with reputation system
- 🚀 Creator discovery and following
- 📝 Content creation and submission
- 💡 AI Explain feature (demo mode)
- 📊 Creator dashboard
- 🔖 Save, like, and share stories
- 🔔 Notification system
- ⚡ Signal Mode for important stories only
- 📱 Mobile-first responsive design
- 🔐 OTP authentication architecture
- 🎨 Premium dark UI

## Architecture

```
NEWSer/
├── index.html
├── assets/
│   ├── css/style.css
│   └── js/
│       ├── app.js          — Main application controller
│       ├── auth.js          — Authentication module
│       ├── auth-provider.js — OTP provider adapter
│       ├── feed.js          — Personalized feed engine
│       ├── news.js          — Demo news data
│       ├── creators.js      — Demo creator data
│       ├── verification.js  — Verification system
│       ├── storage.js       — Local persistence layer
│       ├── promotions.js    — Data-driven promotion system
│       ├── profile.js       — Profile management
│       └── notifications.js — Notifications system
└── README.md
```
